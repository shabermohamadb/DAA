# DAA Lab Programs (Python)

20 Design and Analysis of Algorithms lab experiments written in simple Python.

## Files
- `Ex01.py` to `Ex20.py` — experiment programs in order.

## Run a program
```bash
python Ex01.py
```
Replace `Ex01.py` with the experiment file you want to run.

## Notes
- Graph vertices are numbered from `0` to `n-1`.
- Dijkstra programs expect non-negative edge weights; `0` means no edge.
- TSP programs expect positive costs for available routes; `0` means no route.
- Topological sorting requires a directed acyclic graph (DAG).
